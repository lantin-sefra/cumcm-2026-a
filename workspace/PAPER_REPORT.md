## 2. 本次发现并修复的四处缺陷

接手时草稿已基本成形，实质性问题集中在摘要事实与结构完整性两处。

**其一，摘要夸大了质量收支精度。** 原文写「四问质量收支残差均低于 $10^{-14}$」，但问题二、三的实际残差为 $1.5513\times10^{-14}$，已越过该界。改为「均不超过 $1.6\times10^{-14}$」。

**其二，摘要把浓度差误报成时间差。** 原文称体平均判据「低估时长约 $18\%$」。查 `7_problem3.tex` 与结果数据，$18\%$ 是 $C_{\max}$ 触阈时体平均含水率（$0.1232$~kg/kg）低于阈值的幅度，属浓度量而非时长量。改为「后者会在芯部尚未达标时提前跨过阈值」，不再给出无据的时长百分比。

**其三，创新点章节整体缺失。** 这是国赛评审明确看重、而本工作区生成稿反复漏掉的一节。已在 `10_evaluation.tex` 的「模型的局限」之前补入 `\subsection{本文的创新点}`，四点均为建模层面而非工程层面，且每点按「常规做法 → 本文做法 → 差别」展开：

1. 效应可加分解：净差 $-4.519$~h 严格拆为换物性 $+71.885$~h 与加收缩 $-76.404$~h，恒等残差 $7.1\times10^{-15}$~h；两项各约为净差的十六倍且方向相反，直接相减会把两个大效应误读为一个小效应。
2. 达标判据取逐点最大值而非体平均，并由对称条件与解的空间单调性论证控制点必为轴心；此选择改变的是答案本身而非精度。
3. 骨架随动参数 $\chi$ 显式参数化，同解 $\chi=0$ 与 $\chi=1$ 得 $[50.69,\,52.19]$~h 区间，宽度约为网格离散残余 $0.26$~h 的六倍，据此判定制约精度的是物理闭合而非数值分辨率。
4. 数据不相容如实降格为诊断量：附录 4 的 $\rho(C)$ 与附件 2 的 $R(t)$ 在干物质守恒下相差 $13.42\%$，既不修正实测半径，也不回避矛盾。

**其四，图引用句式单调。** `4_common_model.tex` 中「图~N 给出这一…」骨架出现 4 次，另有三个文件存在相邻的「图作主语」开头。共 8 处改写，句式改为嵌入式、动词引导、后置说明等，每处仍保留显式的图号引用。改后统计：嵌入式 26 / 图作主语 6，相邻同式 0，「给出这一」骨架 0。

## 3. 数据一致性核验

正文所有关键数值均回溯至 `RESULTS.md` 与 `figures/*.json`、`output/*.csv`，逐项比对 15 个头条数字全部吻合：

- 问题一：$0.5$~h 时中心 $33.577~^\circ$C / $2.5500$~kg/kg，表面 $36.786~^\circ$C / $1.511$~kg/kg，残差 $7.41\times10^{-16}$
- 问题二：$3$~h 时中心 $49.85~^\circ$C / $1.766$~kg/kg，表面 $1.008$~kg/kg，残差 $1.5513\times10^{-14}$
- 问题三：$t_{\rm end}=56.706$~h（对照情景 $S_0$ 报 $56.709$~h，为独立复算，正文已分别注明用途）
- 问题四：$t_{\rm end}=52.190$~h，$R_{\rm end}=1.20$~cm，五情景表与加性分解一致
- 不相容诊断：密度比 $2.4131$ 对几何比 $2.7871$，差 $13.42\%$；反演半径 $1.2875$~cm 对实测 $1.1980$~cm，差 $7.47\%$

未出现反向修改 JSON 以迁就正文的情况。

## 4. 核验通过、无需改动的项目

29 张图全部 `[H]` 且尺寸与 `latex_includes.tex` 完全一致；符号表用 `longtable` 保证不被截断；问题二章节无独立编号公式属合规，其引用的 `eq:prop_app3`、`eq:energy` 等均来自公共模型章的稳定标签，按约定不重复整套推导；全文无 `\cref`/`\autoref`，无裸 `\cite`（`\upcite` 尾部造成的疑似命中已用负向后视排除）；无 `itemize`/`enumerate`、无 ASCII 直引号、无占位符。

泄漏扫描的 33 处命中经逐条核对全为假阳性：`../figures/` 是必需的图片路径，`.csv`/`.json` 出现在国赛要求的支撑材料清单中，「断言」为汉语常义。按既有经验，这类误报不作修改。

## 5. 过程中的方法论修正

一次 `grep -cE '\\begin\{(equation|...)\}'` 对全部 13 个文件返回 0，与此前已确认的 29 张内嵌图矛盾。用 `od -c` 转储原始字节确认 `\begin{equation}` 确实存在，定位为 ERE 中 `\{` 的转义问题。关键在于这一错误同时推翻了先前基于同类命令得出的「无漂移浮动体」结论，因此重新核验了全部 8 张表与 29 张图，确认均使用 `[H]`。后续统一改用普通模式匹配。

另有两次内联 heredoc 中的正则被 shell 吞掉反斜杠而报 `bad escape \c`，改为用文件写入工具落盘真实 `.py` 脚本执行。
